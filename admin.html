Each field shows its translation status, and you can override any single translation by hand when you want different wording. How to connect (one time, about 2 minutes)
  1. Open this GitHub page (sign in if asked).
  2. In Token name type: New Delhi Darbar Menu
  3. Under Expiration, choose No expiration (or 1 year).
  4. Under Repository access, pick Only select repositories and choose New-Delhi-Darbar-Menu.
  5. Under Permissions → Repository permissions, find Contents and set it to Read and write.
  6. Click Generate token at the bottom, then copy the token (it starts with github_pat_).
  7. Paste it in the box below and press Connect.
Stored only in this browser and sent only to GitHub. Anyone using this computer could publish, so use a personal device.
