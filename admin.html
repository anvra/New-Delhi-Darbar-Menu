Publish to Page

Commit & Push writes menu.csv, menu-fallback.js and config.js to the repository in one commit, using a GitHub Personal Access Token you provide below. That push automatically triggers GitHub Pages to rebuild the live site — nothing more to click. The token is used only for this action and is never saved — not in this browser's storage, not in any file, not anywhere. You'll need to enter it again next time.
Where do I get a token, and what should it be allowed to do?
  1. Open github.com/settings/personal-access-tokens/new.
  2. Under Repository access, choose Only select repositories and pick New-Delhi-Darbar-Menu only.
  3. Under Permissions → Repository permissions, set Contents to Read and write. Leave everything else at no access.
  4. Set a short expiry (7–30 days) and generate the token, then paste it into the box that appears when you click Commit & Push.
Scoping the token to just this repository and just Contents means even if it were ever misused, it could only edit this one project's files — nothing else in your GitHub account.
Manual publish (without entering a token here)
  1. Click Download the 3 files below.
  2. Replace them in your local copy of the repository: menu.csv → assets/data/, the other two → src/core/.
  3. Commit and push using your own git credentials (git add . && git commit -m "Update menu" && git push).
  4. GitHub Actions rebuilds the public site automatically after the push.
