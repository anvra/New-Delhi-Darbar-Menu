Manage the whole menu site from one place. Type in English; Hindi and Gujarati update automatically.

How this works: enter every item in English only — Hindi and Gujarati are filled in automatically from a shared glossary, so you never type the same dish three times. Each field shows its translation status, and you can override any single translation by hand when you want different wording. Save & Publish updates the menu on this device immediately; to publish for all customers, use the Publish tab and commit the downloaded files to the repository.

Publish to All Customers

Saving stores your changes on this device only. To update the public website, download these three files and replace them in the repository, then commit and push — GitHub Pages republishes within a minute.
  1. Download all three files below.
  2. Put menu.csv into assets/data/.
  3. Put menu-fallback.js and config.js into src/core/.
  4. Commit and push the changes.
