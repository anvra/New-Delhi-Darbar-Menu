Publish Your Changes

Publishing calls the admin auth service, which re-checks that you're signed in as the authorized admin account before writing anything to the repository. Your browser never holds a GitHub token — see worker/ARCHITECTURE.md for how this works.
Manual publish (if the auth service is unavailable)
  1. Click Download the 3 files below.
  2. Replace them in your local copy of the repository: menu.csv → assets/data/, the other two → src/core/.
  3. Commit and push using your own git credentials (git add . && git commit -m "Update menu" && git push).
  4. GitHub Actions rebuilds the public site automatically after the push.
